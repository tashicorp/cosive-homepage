# Cosive — Page titles & meta descriptions

Copy each **Title** into Webflow *Page settings → SEO → Title Tag*, and each **Meta description**
into *Page settings → SEO → Meta Description*. Set Open Graph in the *Open Graph* tab — you can
toggle "use SEO title/description", or paste the **OG title** below where a punchier version helps
(OG description = the meta description).

- Voice: Australian English, active, benefit-first (per `tov/`).
- Title target ≤ 60 chars · Meta description target ~150–160 chars (counts shown in `()`).
- Canonical: enable Webflow's **global self-referencing canonical** (Site settings → SEO) — you
  won't need to paste per-page canonicals. The URLs below are for reference / OG / schema.
- ⚠️ Confirm each canonical path matches the **live Webflow slug** (these mirror the file names).
